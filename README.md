## Featured projects

### 🍽️ SofiaOS — digital menu SaaS for cafés and restaurants

A multi-tenant platform where each business publishes a mobile QR menu and storefront and manages it from an admin dashboard.

- Menu import from PDF, Excel, CSV, JSON, text or a photo, with an editable preview before saving
- Design studio with templates, colour palettes and a live preview
- Bilingual (TR/EN) guest menu with photos, size variants, allergens and nutrition info
- Guided onboarding, QR code generation and printable QR formats
- Table ordering, kitchen display and POS exist in the codebase but are **not yet part of the commercial product**

**Stack:** Next.js · React · TypeScript · Tailwind CSS · Supabase · Google Gemini · next-intl
**Live:** [sofiaos.com.tr](https://sofiaos.com.tr) · [Sample storefront](https://sofiaos.com.tr/sofia-demo)

### 📦 KarePaket — social media content package generator

A browser-only MVP that turns product details into an editable content package for a launch or promotion.

- 3 campaign ideas, 5 image prompts, 3 Instagram captions, a 15-second video plan and 6 camera angles
- Five brand tones and four campaign goals; every generated field is editable
- Export as Markdown or JSON, or copy to the clipboard
- **Template-based: the current version has no AI integration**

**Stack:** React · TypeScript · Vite · Vitest
**Status:** Early prototype (private repository)
