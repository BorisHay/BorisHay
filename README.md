## Featured projects

### 🍽️ SofiaOS — digital menu platform for cafés and restaurants
A multi-tenant QR menu and business storefront platform. Owners import their menu from PDF, Excel, CSV or a photo, design it in a studio with live preview, and publish a bilingual (TR/EN) mobile menu. Table ordering, kitchen display and POS are implemented in the codebase but are not yet part of the commercial product.

**Stack:** Next.js 16 · React 19 · TypeScript · Tailwind CSS · Supabase (Postgres, Auth, Realtime, Storage) · Google Gemini
**Status:** Sofia QR Menu is live in production · 🌐 [sofiaos.com.tr](https://sofiaos.com.tr) · [Sample storefront](https://sofiaos.com.tr/sofia-demo)

### 📦 KarePaket — social media content package generator
A browser-only MVP that turns basic product details into an editable content package: campaign ideas, image prompts, Instagram captions, a 15-second video plan and camera angles, exportable as Markdown or JSON. The current version is template-based — no AI integration.

**Stack:** React 19 · TypeScript · Vite · Vitest
**Status:** Early prototype (private repository)
