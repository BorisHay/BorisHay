## Featured projects

### 🍽️ SofiaOS — digital menu SaaS for cafés and restaurants

A multi-tenant platform where each business publishes a mobile QR menu and a public storefront and manages everything from an admin panel.

- Menu import from PDF, Excel, CSV, JSON, plain text or a photo, with an editable preview. Prices are never guessed, and the import is written in one database transaction.
- Design studio with layout templates, colour palettes and a live preview
- Bilingual (TR/EN) guest menu with photos, size variants, allergens and nutrition values; AI estimates are labelled as estimates
- 7-step onboarding wizard, QR code generation and printable formats
- Tenant isolation enforced in Postgres with Row Level Security and `SECURITY DEFINER` functions
- Table ordering, kitchen display and POS are implemented in the codebase but **not yet part of the commercial product**

**Stack:** Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · Supabase (Postgres, Auth, Realtime, Storage) · Google Gemini · next-intl
**Status:** Sofia QR Menu is live in production · 🌐 [sofiaos.com.tr](https://sofiaos.com.tr) · [Sample storefront](https://sofiaos.com.tr/sofia-demo)

### 📦 KarePaket — social media content package generator

A browser-only MVP that turns basic product details into an editable content package.

- 3 campaign ideas, 5 image-generation prompts, 3 Instagram captions, a 15-second video plan and 6 camera angles
- Five brand tones and four campaign goals; every generated field can be edited in place
- Export as Markdown or JSON, or copy to the clipboard; single-file HTML build that runs without a server
- Form validation and unit tests with Vitest
- **Template-based: no AI integration in the current version.** Nothing leaves the browser and no claims are invented.

**Stack:** React 19 · TypeScript · Vite · Vitest
**Status:** Early prototype (private repository)
